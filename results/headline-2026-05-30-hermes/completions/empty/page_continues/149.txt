Answer: I've found the answer, thanks to a response from David Cantrell on the CPAN Testers mailing list.

The problem is that the test file was using Test::More, but not declaring a plan. That's fine in most cases, but causes a problem with the Test::Harness version that's used on the CPAN Testers box. The solution is to declare a plan.

I've updated the test file like this:

\begin{code}
use strict;
use warnings;
use Test::More tests => 1; # <--- this is the important line
use File::Find::Rule;

my @files
