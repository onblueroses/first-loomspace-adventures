Comment: The browser already saved it with a `.txt` extension, so you don't need to do anything.

Answer: When you save the file, your browser should automatically add the `.txt` extension.  This is a common file extension for plain text files.  If your browser does not add the `.txt` extension, you can add it yourself by renaming the file and adding `.txt` to the end of the file name after you have downloaded it.

The purpose of the `.txt` extension is to tell the operating system and other software that the file contains plain text.  This helps the software determine how to handle the file.
