Comment: Are you using a WebSphere Application Server? If so, what version?

Answer: The `OutOfMemoryError` is due to insufficient space in the Java heap. The heap size is set using the `-Xms` and `-Xmx` JVM options when starting the application.

These options are usually set in the application's startup script. If you are using a third party application server or web container, you may need to refer to the documentation to configure the JVM options.

\item Click the name of the server for which you want to increase the heap size.
