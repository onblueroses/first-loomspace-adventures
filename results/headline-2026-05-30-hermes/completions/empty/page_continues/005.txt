Hi Prasanna,

If you have access to your php.ini file, you should check to make sure the following settings are large enough to handle your file uploads:

upload_max_filesize
post_max_size

For example, if your maximum uploaded file size is set to 100MB in Moodle, you should have something like this in your php.ini file:

upload_max_filesize = 100M
post_max_size = 100M
