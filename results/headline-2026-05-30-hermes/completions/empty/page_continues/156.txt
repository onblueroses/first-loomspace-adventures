## Vector Operations in Python

The NumPy library in Python provides a convenient way to perform vector operations. Let's explore some of the basic operations:

1. Vector Addition:
   - To add two vectors, we simply add their corresponding elements.
   - Example:
     ```python
     import numpy as np
     
     v1 = np.array([1, 2, 3])
     v2 = np.array([4, 5, 6])
     
     result = v1 + v2
     print(result)  # Output: [5, 7, 9]
     ```

2. Vector Subtraction:
   - To subtract two vectors, we subtract their corresponding elements.
   - Example:
     ```python
     import numpy as np
     
     v1 = np.array([1, 2, 3])
     v2 = np.array([4, 5, 6])
     
     result = v1 - v2
     print(result)  # Output: [-3, -3, -3]
     ```
