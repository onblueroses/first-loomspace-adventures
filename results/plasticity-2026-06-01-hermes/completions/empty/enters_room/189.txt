The `new` keyword is used in Java to create an object.  In this case, the `new` keyword is used to create an array object of `int` with 4 elements.

\begin{code}
int[] a = new int[4];
\end{code}

The `int[]` tells Java that the variable `a` will hold an array of `int`.  The `new int[4]` tells Java to create an array object of `int` with 4 elements.
