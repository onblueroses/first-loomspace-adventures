So you are using the manual way of building the sitemap. I tried that also, but I use now the indexmenu plugin. It builds the sitemap automatically based on the namespaces and pages. I like it more because it is less work.
To display an image you should use this syntax:
```
{{ wiki:dokuwiki-128.png}}
```
When you use [wiki:dokuwiki-128.png] it will make a link to that image instead of displaying it.
