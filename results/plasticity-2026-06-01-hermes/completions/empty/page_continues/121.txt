If you want to develop Java applications, download the Java Development Kit, or JDK. The JDK includes the JRE, so you do not have to download both separately.

From: http://www.oracle.com/technetwork/java/javase/downloads/index.html

If you're just running Java, you only need the JRE. If you're developing Java software, you need the JDK. The JDK includes the JRE.
