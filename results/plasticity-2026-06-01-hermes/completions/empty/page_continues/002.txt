 "This function works by creating a new connection to the database server. If you use persistent connections, every time you call mysql_connect() with the same parameter values, you will get the same connection identifier. For example, you can iterate over the same MySQL connection like this:"

\begin{code}
<?php

for ($i = 0; $i < 10; $i++) {
    $dbh = mysql_connect('localhost', 'username', 'password', true);
    print_r(mysql_thread_id($dbh));
    mysql_close($dbh);
}

?>
\end{code}

The `true` parameter indicates that the connection should be a persistent one.
