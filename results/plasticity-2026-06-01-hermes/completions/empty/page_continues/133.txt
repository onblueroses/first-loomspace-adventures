Original answer:

People generally don't recommend using MD5 or SHA1 for password hashing because they are fast. Instead, use a slow algorithm like [bcrypt](http://en.wikipedia.org/wiki/Bcrypt) or [scrypt](http://www.tarsnap.com/scrypt.html).

You can, for example, use PHP's [crypt()](http://php.net/manual/en/function.crypt.php) function with the Blowfish algorithm, which uses bcrypt.
