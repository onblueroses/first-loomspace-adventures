 "To create a new database, use the CREATE DATABASE statement as shown in the following example:"

```
CREATE DATABASE testdb;
```

The book continues: "If you try to create a database that already exists, MySQL will issue an error. To avoid this error, and to ensure that you're creating the database only if it doesn't already exist, use the IF NOT EXISTS clause:"

```
CREATE DATABASE IF NOT EXISTS testdb;
```

The page continues: "To view a list of all databases, use the SHOW DATABASES statement:"

```
SHOW DATABASES;
```
