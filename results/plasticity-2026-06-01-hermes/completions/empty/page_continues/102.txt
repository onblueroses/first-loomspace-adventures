Answer: I believe you can create your own custom message box by creating a custom form that looks like a message box. Add the "Yes", "No", and "Cancel" buttons and set their DialogResult property to Yes, No and Cancel respectively. Then you can call the custom form using ShowDialog() and it will return the appropriate DialogResult value.

Answer: As others have pointed out, the standard `MessageBox` does not support a `Yes`, `No`, `Cancel` button combination.  You can create a custom `Form` with three buttons, or you can use a standard `MessageBox` with `OK`, `Cancel` buttons and add an extra `CheckBox` to the `MessageBox` for the `Yes` option.
