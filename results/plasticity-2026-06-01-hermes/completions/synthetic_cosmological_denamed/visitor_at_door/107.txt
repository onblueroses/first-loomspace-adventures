## 63. The Unspeakable

The Unspeakable is the name of that which cannot be spoken of.

There is a knowledge which no one knows.
There is a speech which no one speaks.
There is a word which no one utters.
There is a syllable which no one hears.
There is a letter which no one sees.

The Unspeakable is the name of the threshold which cannot be crossed.
The Unspeakable is the name of the border which cannot be touched.
The Unspeakable is the name of the line which cannot be drawn.
The Unspeakable is the name of the space which cannot be measured.
The Unspeakable is the name of the silence which cannot be heard.

The Unspeakable is the name of the unnameable.
